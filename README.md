# پورتفولیوی مهدی منتظری

نسخه‌ی استاتیک و ریسپانسیو با HTML، CSS و JavaScript خالص؛ بدون نیاز به نصب فریم‌ورک یا build. طراحی جدید از ویدیوی مرجع الهام گرفته و شامل انیمیشن‌های اسکرول، افکت‌های سه‌بعدی و تعامل با ماوس است.

## اجرا

1. فایل ZIP را Extract کن.
2. وارد پوشه‌ی `portfolio` شو.
3. فایل `index.html` را باز کن. برای تست بهتر می‌توانی در VS Code از Live Server استفاده کنی.

## ویرایش محتوا

برای تغییر متن‌ها، پروژه‌ها، مهارت‌ها و افتخارات فقط فایل `data.js` را باز کن. بعد از ذخیره، صفحه را Refresh کن.

### اطلاعات شخصی

در بخش `PROFILE` نام، عنوان، معرفی، ایمیل، GitHub و مسیر رزومه را تغییر بده.

### اضافه کردن پروژه

در آرایه‌ی `PROJECTS` یک آبجکت جدید اضافه کن:

```js
{
  id: "my-project",                 // شناسه یکتا و انگلیسی
  title: "My Project",              // نام پروژه
  subtitle: "A short subtitle",     // زیرعنوان
  description: "What it does...",   // توضیح کامل
  category: "web",                  // web | android | robotics
  tags: ["Python", "Django"],       // فناوری‌ها
  year: "2026",                     // سال یا بازه
  status: "In progress",            // برچسب کوتاه
  visual: "commerce",               // نوع کاور: commerce, mobile, robot, sensors, dashboard, mobile-alt, shop, apps
  link: ""                           // لینک واقعی پروژه؛ در صورت نداشتن، خالی بماند
}
```

هر پروژه به‌صورت خودکار کارت می‌گیرد و با کلیک روی کارت، پنجره‌ی جزئیات باز می‌شود. لینک پروژه فقط وقتی نمایش داده می‌شود که مقدار `link` را با آدرس واقعی پر کرده باشی. برای کاور جدید، می‌توانی نوع visual و CSS مربوط به آن را در `style.css` توسعه بدهی.

### مهارت‌ها

در آرایه‌ی `SKILLS` عنوان، توضیحات و فناوری‌های هر حوزه را ویرایش کن. بخش `OTHER_TOOLS` برای ابزارهای تکمیلی زیر آکاردئون است.

### افتخارات

در `ACHIEVEMENTS.medals` مدال‌ها و جایزه‌ها را اضافه، حذف یا ویرایش کن. عدد بالای بخش از `statNumber` خوانده می‌شود. اطلاعات این نسخه بر اساس سه جایزه‌ی بین‌المللی درج‌شده در رزومه تنظیم شده است.

### شبکه‌های اجتماعی و رزومه

آرایه‌ی `SOCIAL_LINKS` در `data.js` لینک‌های بالای صفحه و فوتر را کنترل می‌کند. اگر لینک شبکه‌ی دیگری داری، یک مورد جدید با `label`, `href` و `type` اضافه کن.

## شخصی‌سازی ظاهر و انیمیشن

- رنگ‌ها و فونت‌ها: ابتدای `style.css` در `:root`
- اندازه‌ها و چیدمان واکنش‌گرا: بخش Responsive در انتهای `style.css`
- انیمیشن‌ها و تعامل‌ها: `script.js`
- ساختار صفحه: `index.html`

### افکت‌های فعلی

- ورود حرف‌به‌حرف عنوان Hero
- پرتره‌ی شناور و پارالاکس چندلایه
- مدارهای سه‌بعدی متحرک در Hero
- هاله‌ی نور دنبال‌کننده‌ی ماوس
- tilt سه‌بعدی نرم کارت‌های پروژه و افتخارات با دنبال‌کردن اشاره‌گر و برگشت نرم هنگام خروج ماوس
- نور موضعی روی کارت‌ها و حرکت عمقی جداگانه برای عنوان، محتوا و کاور
- کاورهای گرافیکی متحرک با افکت نور گذرا، شناوری و عمق سه‌بعدی؛ انیمیشن کاورها فقط وقتی کارت نزدیک محدوده‌ی دید است اجرا می‌شود
- حرکت مستقل و نرم پرتره با ماوس و اسکرول؛ متغیرهای این دو افکت جدا هستند تا با هم تداخل نکنند
- انیمیشن پرتره هنگام خروج از Hero متوقف می‌شود و از scale/blur سنگین روی خود تصویر استفاده نمی‌کند
- سازوکار امن برای انیمیشن اسکرول؛ علاوه بر IntersectionObserver، بررسی اسکرول سریع هم وجود دارد تا محتوای ردشده مخفی نماند
- ورود staggered بخش‌ها هنگام اسکرول
- آکاردئون مهارت‌ها با باز و بسته‌شدن نرم
- فیلتر زنده‌ی پروژه‌ها و پنجره‌ی جزئیات
- دکمه‌های magnetic و progress bar اسکرول
- منوی موبایل و breakpointهای تبلت/موبایل

تنظیم `prefers-reduced-motion` رعایت شده است تا کاربرانی که حرکت کمتر ترجیح می‌دهند انیمیشن‌های شدید را نبینند.

## نکته پیش از انتشار

لینک پروژه‌ها در حالت پیش‌فرض خالی است تا اشتباهاً به صفحه‌ی GitHub عمومی وصل نشود. فقط لینک واقعی مخزن یا دمو را در `data.js` وارد کن. ایمیل، موقعیت مکانی و لینک GitHub را نیز پیش از انتشار عمومی بررسی کن.

### بررسی عملکرد

نسخه‌ی فعلی در Chromium با عرض‌های 390، 768، 1024 و 1440 پیکسل رندر و بررسی شده است. حرکت کارت و پرتره، برگشت پس از خروج اشاره‌گر، فیلتر پروژه‌ها، باز و بسته‌شدن پنجره‌ی جزئیات، منوی موبایل و اسکرول سریع بررسی شده‌اند. در این تست‌ها خطای JavaScript یا اسکرول افقی ناخواسته دیده نشد.
